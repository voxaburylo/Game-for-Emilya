Оригінальні 3D-персонажі «Острова Емілії»
========================================

Редаговане джерело: ../models/characters.blend (Blender 4.5 LTS).
Окремі моделі з вузлами для руху: ../models/girl.glb, ../models/dog.glb.
Ігрові меші: ../models/characters.json + characters.bin.

Повторна побудова:
  blender --background --python authoring/build_characters.py
Мініатюри гардероба:
  blender --background --python authoring/render_thumbnails.py
Контактний аркуш усіх шести образів:
  blender --background --python authoring/render_wardrobe.py

Скрипт використовує лише Python API Blender. Зовнішніх пакетів, зображень,
платних сервісів або завантажених сторонніх персонажів не потрібно.

У Blender відкрийте колекції Girl / Dog. Кожна зачіска, сукня та пара взуття
лежить у власній колекції hair0..4 / dress0..5 / shoes0..3. Для примірки
увімкніть одну колекцію кожного типу, вимкнувши попередню. Base залишається
видимою. Рухомі частини прив'язані до named Empty-вузлів: head, armL/R,
legL/R, eyeL/R, earL/R, backL/R та tail. Очі й вуха є дочірніми вузлами голови.

Форми обличчя, пасма, повіки, складки тканини, шви, взуття та вуха побудовані
як окремо спроєктовані сітки. Плавні руки, мордочка, тулуб і лапи песика
з'єднані voxel remesh, згладжені та забарвлені по вершинах. У сцені є студійне
освітлення й камера для рендера. Розмір одиниці відповідає ігровому світу.

Ігровий експорт окремо спрощує геометрію, зберігаючи детальніше .blend-джерело.
Він групує меші за матеріалом, вузлом руху й варіантом гардероба. Геометрія
спільна для примірок і відображення в дзеркалі; змінні кольори мають окремі
матеріали. Бінарний файл завантажується до створення світу та кешується для
офлайн-гри. Blender і GLB-файли для запуску гри не потрібні.

Матеріали й геометрія створені спеціально для цього проєкту. Сторонніх
ліцензій на персонажів немає; ліцензія Blender не поширюється на створені
ним зображення та моделі. Наявна атрибуція аудіозаписів гри не змінювалася.
